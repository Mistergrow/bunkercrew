# BUNKERCREW v0.1.0-beta — First Public Beta

Local publication candidate; not yet published.

BUNKERCREW is a 1–4 player co-op tower defense & crafting game built with
Godot 4.7.2. Mine. Build. Defend. Survive.

Source includes solo story and onboarding, local/LAN/online co-op paths,
resource gathering, bunker excavation, production, workbench crafting, waves,
crew selection, convoy repairs and German/English localization.

The first public series uses `0.1.0-beta` in game and `v0.1.0-beta` as the
proposed tag. Earlier dated beta milestones and internal packages are retained.
Network identity remains `bunkercrew-net-20`; world-data revision remains 5.

Linux and Windows x86_64 are configured export targets. Final release artifacts
and their exact verification status are recorded in the publication report;
export availability alone does not establish platform acceptance. Native
Windows play, four-player Internet tests across independent connections,
long-session play, subjective listening and weaker-hardware performance remain
human acceptance tasks. Online play requires a compatible available relay.
