# Weapon reload source recordings

These archived recordings are licensed **CC0 1.0** by their uploaders. Source
pages were checked on 2026-10-01; adjacent HTML copies retain the author and
license evidence. `sources.json` records download URLs and SHA-256 hashes.

- [SpringySpringo — Gun reload sounds](https://opengameart.org/content/gun-reload-sounds):
  `gunreload1.wav`, `assaultriflereload1.wav`, `shotguncock.wav`. The author
  identifies these as recordings made with airsoft guns.
- [Brian MacIntosh (BMacZero) — Gun Reload Sound Effects](https://opengameart.org/content/gun-reload-sound-effects):
  `clipload1.wav`, `clipload2.wav`, `singlebullet1.wav`.

License: <https://creativecommons.org/publicdomain/zero/1.0/>.
Credit is optional under the source declarations; authors are retained here.

The game ships edited mono phase effects generated by
`tools/generate_weapon_audio.py`. Edits include source cuts, fixed-speed
resampling, filtering, layering, mild compression and edge fades. These source
recordings are not our original recordings. The parent `.gdignore` keeps raw
sources out of Godot imports. No subjective listening assessment is claimed.
