# BUNKERCREW

**1–4 player co-op tower defense & crafting game.**

Mine. Build. Defend. Survive.

## About

Build and defend an underground industrial bunker. Gather resources, excavate
floors, operate production machinery, craft equipment and fight incoming waves.
BUNKERCREW is built with Godot 4.7.2 using the Compatibility renderer.

## Current Beta

The first public release candidate is **v0.1.0-beta**. Earlier dated packages are
internal development builds; their history is retained in [CHANGELOG.md](CHANGELOG.md).
This repository is being prepared for publication. A release is available only
after the human publication decision.

## Features

- Solo story with campaign progression and guided first-shift onboarding.
- Co-op for up to four players, with local input, LAN and online room-code paths.
- Resource gathering, excavation, production machines and workbench crafting.
- Bunker defenses, weapons, upgrades and enemy waves.
- Eight crew characters, German and English text and recorded synthetic dialogue.
- Convoy travel and roadside repairs, adaptive music and controller input.

These features are present in source. Native Windows acceptance, four-player
Internet play across independent connections, long sessions, listening tests and
performance on weaker hardware still require human validation. Online play also
requires an available compatible relay. See [network documentation](docs/network-server.md).

## Controls

Default player-one bindings from `scripts/input_setup.gd`:

| Action | Input |
| --- | --- |
| Move / climb | A, D / W, S |
| Jump | Space |
| Interact / read / open workbench menu | E |
| Drop / reload | Q / R |
| Aim / fire | Mouse / left mouse button |
| Cycle material / target / weapon | Tab / F / C |
| Store in crate (hold) / deploy | G / B |
| Upgrades / personnel / journal | T / P / J |
| Field manual / pause | F1 / Escape |

Controller bindings and additional player controls are available in the in-game
field manual. Use matching builds for co-op.

## Running from Source

Install Godot **4.7.2** and open `project.godot`, or run:

```bash
godot --headless --path . --editor --recovery-mode --import --quit
godot --path .
```

Source textures, fonts, audio, native audio libraries and their metadata are
required. `.godot/` is regenerated by Godot. Live music uses the included native
audio extension; rebuilding it is documented in
[native/bunkercrew_audio/README.md](native/bunkercrew_audio/README.md).
The optional `addons/godot_mcp` editor plugin is retained in source; it is not a
game runtime requirement.

## Building

Install matching Godot 4.7.2 export templates. Export presets support Linux and
Windows x86_64. For clean release exports to a new local directory:

```bash
mkdir -p beta/public-release-candidate/linux beta/public-release-candidate/windows
godot --headless --path . --export-release "Ubuntu Beta" beta/public-release-candidate/linux/Bunkercrew.x86_64
godot --headless --path . --export-release "Windows Beta" beta/public-release-candidate/windows/Bunkercrew.exe
```

Copy the corresponding native audio library from `assets/audio/live/` beside
each executable and retain license notices. These commands export executables;
they do not create a fully validated distribution. The existing
`tools/build_beta.py` performs broader checks and packaging, uses debug exports,
and refuses to overwrite an existing version directory. Preserve old packages.
